# DriveEasy

DriveEasy est un site web de location de véhicules de courte durée.  
Ce projet a été réalisé dans le but de digitaliser les réservations, qui étaient auparavant gérées par téléphone et par email.

## Fonctionnalités
- Affichage des véhicules disponibles
- Consultation du détail d’un véhicule
- Réservation en ligne via un formulaire
- Enregistrement des réservations dans une base de données MySQL

## Prérequis
- XAMPP (Apache + MySQL)
- Navigateur web
- Git (optionnel)
